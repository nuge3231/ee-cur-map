# ee-cur-map

### 전기공학 교과과정[맵] - 학점은행제 타전공 과정

전기공학 38개 과목을 전기, 중기, 후기 학습 순서로 정리한 인터랙티브 HTML 맵입니다.

- 전문분야별 색상과 전공필수 and 공통 핵심 권장 과목 표시
- 과목을 클릭하거나 마우스를 올리면 연결된 학습 경로 강조

## 사용 방법

`dist/index.html`을 브라우저에서 열면 됩니다. 별도 설치나 인터넷 연결이 필요하지 않음

> 학습 순서와 연결 관계는 추천이며, 공식 선수요건은 학교 강의계획서를 확인하세요.
